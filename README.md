# EKS + Karpenter with Graviton and Spot

Technical assignment — two independent deliverables.

| Folder | Contents |
|---|---|
| **[`terraform/`](./terraform/)** | Terraform that deploys an EKS cluster into a dedicated VPC with Karpenter provisioning **both arm64 (Graviton) and amd64 (x86)** nodes on Spot with On-Demand fallback. Includes ready-to-run examples showing how a developer targets either architecture. |
| **[`architecture/`](./architecture/)** | Cloud architecture design for *Innovate Inc.* — account structure, network design, compute platform and database, with diagrams. |

Each folder has its own README with the detail.
